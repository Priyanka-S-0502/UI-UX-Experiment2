# UI-UX-Experiment2

## Aim:
To design a basic Food Delivery Mobile Application Layout with logo using UI/UX design principles, Gestalt principles, interactive elements, and branding guidelines.

## Algorithm:
Step 1: Select the case study for a Food Delivery App and analyze required features like food browsing, restaurant details, cart, and checkout.

Step 2: Open Figma or Canva and create a new mobile app design project.

Step 3: Design the basic wireframe for three app pages:

Home Page
Restaurant / Food Details Page
Cart / Checkout Page

Step 4: Apply Gestalt principles such as proximity, similarity, continuity, and alignment to organize content effectively.

Step 5: Add UI elements like:

Navigation bar
Search bar
Food cards
Category icons
Add-to-cart buttons
Checkout button

Step 6: Create interaction behaviors such as button clicks, navigation flow, and feedback responses.

Step 7: Design a custom food app logo using Canva with proper colors, typography, and branding style.

Step 8: Integrate the logo into all app screens.

Step 9: Apply usability principles to ensure the design is intuitive, responsive, and visually appealing.

Step 10: Review and finalize the complete app layout.
